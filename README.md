# Sistem Kasir Sederhana dengan Python

## Deskripsi
Proyek ini merupakan program kasir sederhana yang dibuat menggunakan Python sebagai latihan pemrograman dasar.

## Fitur
- Input nama pembeli dan produk
- Pemilihan kategori produk
- Input harga dan jumlah pembelian
- Perhitungan subtotal pembayaran
- Tampilan struk transaksi dengan format rupiah Indonesia

## Konsep Python yang Digunakan
- Variabel dan tipe data
- Input dan output
- Konversi tipe data
- Operasi aritmetika
- List dan dictionary
- F-string dan manipulasi string

## Tujuan
Memahami penerapan dasar Python melalui simulasi transaksi kasir sederhana.
